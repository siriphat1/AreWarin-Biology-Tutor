AreWarin Tutor OS V19.3 Calendar Pro

เพิ่ม:
- ตารางสอนแบบ Week Calendar คล้าย Google Calendar (จันทร์–อาทิตย์)
- เวลา 07:00–22:00 พร้อมเส้นทุก 30 นาที / ชั่วโมง
- ปุ่มสัปดาห์ก่อน / วันนี้ / สัปดาห์ถัดไป
- สลับมุมมอง ปฏิทิน / รายการ
- คลิกพื้นที่ว่างในตาราง -> เปิดฟอร์มเพิ่มตารางพร้อมวัน/เวลาเริ่ม
- คลิกคาบ -> เปิดแก้ไขตาราง
- แสดงสถานะ นัดสอน / เลื่อนนัด / กำลังสอน / สอนแล้ว
- รองรับคาบชนกัน โดยแบ่งพื้นที่ข้างกัน
- Quick Duration: 30 นาที, 1 ชม., 1.5 ชม., 2 ชม., 2.5 ชม., 3 ชม.
- เลือกเวลาเริ่มแล้วกดระยะเวลา -> คำนวณเวลาจบอัตโนมัติ
- จำระยะเวลาที่ใช้ล่าสุดสำหรับการสร้างนัดครั้งถัดไป
- ฟังก์ชัน RPC / ฐานข้อมูลเดิมยังใช้เหมือนเดิม ไม่ต้องรัน SQL

ติดตั้ง:
1. อัปโหลด index.html แทน Tutor OS เดิม
2. อัปโหลด app.js ในโฟลเดอร์เดียวกัน
3. Ctrl + Shift + R

หมายเหตุ:
ไฟล์ HTML อ้าง ./app.js ดังนั้นต้องเปลี่ยนทั้ง 2 ไฟล์พร้อมกัน
