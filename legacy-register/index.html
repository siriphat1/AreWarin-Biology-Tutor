STEP 01

ตรวจสอบเบอร์โทร

ใช้เบอร์ที่เคยแจ้งกับ AreWarin หากยังไม่มี Student Profile ระบบจะให้กรอกข้อมูลต่อ

ระบบใช้เบอร์โทรเพื่อป้องกันการสร้าง Student Profile ซ้ำ
STEP 02

ข้อมูลนักเรียนและผู้ปกครอง

แบ่งข้อมูลเป็น 2 ส่วนชัดเจน เพื่อให้ตรวจสอบและแก้ไขภายหลังได้ง่าย

ข้อมูลนักเรียนข้อมูลหลักสำหรับ Student Profile
ข้อมูลผู้ปกครองกรอกเท่าที่สะดวกสำหรับการติดต่อกรณีจำเป็น
STEP 03

ประกาศความเป็นส่วนตัว (PDPA)

อ่านรายละเอียดก่อนกรอกประวัติคอร์ส เพื่อให้ทราบว่าข้อมูลจะถูกใช้และดูแลอย่างไร

1. ข้อมูลที่เก็บ

AreWarin จะเก็บข้อมูลที่คุณกรอก เช่น ชื่อ ชื่อเล่น เบอร์โทร อีเมล LINE ID โรงเรียน/มหาวิทยาลัย ระดับชั้น คณะ/สาขา จังหวัด ข้อมูลผู้ปกครอง และประวัติคอร์สที่เคยเรียน

2. วัตถุประสงค์การใช้ข้อมูล

  • สร้างและดูแล Student Profile
  • ตรวจสอบประวัติการเรียนเดิมและเชื่อมกับ Course Catalog
  • ใช้เพื่อการติดต่อ การจัดการเรียน และงานธุรการที่เกี่ยวข้อง
  • ป้องกันข้อมูลซ้ำและรักษาความถูกต้องของฐานข้อมูล

3. การเข้าถึงและการเก็บรักษา

การเข้าถึงจะจำกัดตามหน้าที่ของบุคลากร เช่น Manager/Admin และผู้เกี่ยวข้องกับการจัดการเรียน ข้อมูลจะไม่ถูกเผยแพร่เป็นสาธารณะจากแบบฟอร์มนี้

4. สิทธิของเจ้าของข้อมูล

คุณสามารถติดต่อ AreWarin เพื่อขอเข้าถึง แก้ไข หรือสอบถามการใช้ข้อมูลได้ การลบข้อมูลบางรายการอาจต้องพิจารณาข้อมูลที่จำเป็นต่อประวัติการเรียน การเงิน หรือข้อกำหนดที่เกี่ยวข้อง

STEP 04

ประวัติคอร์สที่เคยเรียน

เลือกจาก Course Catalog ของ AreWarin พร้อมภาพคอร์ส หากหาไม่เจอสามารถกรอกชื่อคอร์สเองได้

แสดงทั้งคอร์สที่เปิดอยู่และคอร์สเก่าที่ปิดรับแล้ว เพื่อให้เลือกประวัติเดิมได้ครบ
ประวัติคอร์สเพิ่มได้สูงสุด 10 รายการ
หากจำชื่อคอร์สไม่ได้ตรงทั้งหมด ให้เลือก “ไม่พบในรายการ / กรอกเอง” แล้วระบุชื่อวิชาที่ใกล้เคียงที่สุด
